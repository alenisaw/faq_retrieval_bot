# Фронтенд AITU FAQ

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4. Вся логика — в Python-бэкенде, фронт только
показывает результаты API (`backend/src/api`).

| Страница | Что на ней |
|---|---|
| `/` — Спросить | вопрос → лучший ответ с маркером на совпавших словах, тема, совпадение, метод; похожие ответы; просмотр базы по темам |
| `/compare` — Сравнить методы | один вопрос сразу всеми методами, одинаковые ответы разных методов подсвечены одним цветом |
| `/insights` — Как это работает | метрики методов (графики и таблица), SQL-отчёты из `faq.db`, графики EDA из `reports/figures` |

## Запуск

```bash
cd frontend
npm install
npm run dev                  # http://localhost:3000, API ждёт на http://localhost:8000
```

Адрес API — переменная `NEXT_PUBLIC_API_URL` (по умолчанию `http://localhost:8000`). Она вшивается
в сборку, поэтому при деплое задаётся до `npm run build`. Бэкенд должен разрешать этот домен в
`API_CORS_ORIGINS`.

Docker: `docker compose --profile frontend up --build` из корня репозитория.

## Устройство

```
app/                 # страницы и общий макет (шапка, подвал)
components/ask/      # «Спросить»: форма, лист ответа, темы
components/compare/  # «Сравнить методы»
components/insights/ # метрики, SQL-отчёты, графики EDA
components/ui/       # кнопка, скелетон, шкала совпадения (в стиле shadcn/ui)
lib/api.ts           # все запросы к API и типы (копия backend/src/api/schemas.py)
lib/highlight.ts     # подсветка совпавших слов по началу слова
```

Дизайн: палитра «бумага / чернила / ультрамарин», жёлтый маркер только на совпавших словах, шрифты
Unbounded (заголовки) и Onest (текст) из `@fontsource` — работают без интернета. Единственная анимация —
маркер; при `prefers-reduced-motion` она отключена.

Маркер — подсказка для человека: он показывает общие с вопросом слова, но не объясняет, почему
нейросетевой метод выбрал ответ.
